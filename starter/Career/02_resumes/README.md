# Resumes

- Keep **one base resume per kind of role** you're aiming for (for example `base_customer-success.docx`, `base_support-lead.docx`). Tailor copies go in each job folder.
- Keep a **safe copy for AI** (`resume-for-ai`): no home address, phone number or date of birth.
- Name files without dates. Dates belong inside the resume.
- Log every fix in `corrections-log.md` so the same mistake never comes back.
